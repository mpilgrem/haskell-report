Contributing
============

Subject to the following, contributions are welcome!

Copyright and licensing
-----------------------

An objective of this project is that the Haskell 2024 Language Report should
have restictions over its use that are no more restrictive than those of the
Haskell 2010 Language Report.

Consequently, a condition of making a contribution is that each contributor
agrees that, to the extent that the contributor has any copyright in the
contribution, the contributor releases it under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

Compliance with laws and regulations
------------------------------------

An objective of this project is that it should comply with all applicable laws
and regulations, including those that relate to copyright and other intellectual
property rights.

A condition of making a contribution is that each contributor confirms that, to
the best of the contributor's knowledge and understanding, the contribution does
not breach any law or regulation.

No machine contributions
------------------------

An objective of this project is that the final Haskell 2024 Language Report:

(1) should be as authoritative as the Haskell 2010 Language Report and the
    content of approved proposals and the GHC User's Guide as they relate to
    language features enabled by GHC's `GHC2024` language feature; and

(2) should be of a quality no less than the quality of the Haskell 2010 Language
    Report.

To meet that objective, this project considers it important that a contributor
is responsible, and accountable, for the contributor's contributions.
Consequently, contributions by machines are not accepted, regardless of their
merits.

Machine-assisted contributions
------------------------------

Subject to the other requirements and the following, machine-assisted
contributions are acceptable: a contributor should disclose if _significant_ use
has been made of _AI tools_ in preparing the contribution.

For this purpose, _significant_ means any aspect of the contribution which, in
the judgment of the contributor, could substantially affect the Haskell 2024
Language Report; and an _AI tool_ means technology that uses a large language
model (LLM) or otherwise employs logic that makes the relationship between
inputs and outputs hard or impossible to understand.

Extent of modifications to the Haskell 2010 Language Report
-----------------------------------------------------------

An objective of this project is that modifications to the Haskell 2010 Language
Report should be no more than required to meet the objectives of the Haskell
2024 Language Report

Consistency with the Haskell 2010 Language Report
-------------------------------------------------

An objective of this project is that modifications to the Haskell 2010 Language
Report should be consistent with:

(1) the unmodified content of the Haskell 2010 Language Report; and

(2) other accepted modifications to the Haskell 2010 Language Report.

Codification of matters already agreed
--------------------------------------

Objectives of this project are:

(1) to codify matters that are already agreed (in the form of approved proposals
    for language features to be implemented by GHC and the implementation of
    those language features in GHC); and

(2) to not re-open debates about the merits and drawbacks of those matters.

Consequently, contributions that modify the Haskell 2010 Language Report should
not debate the merits or drawbacks of matters that are already agreed. Other
forums are better placed for such debates.
